⚠ 安全与隐私提醒

1. 数据删除与备份

剪贴板数据默认不纳入自动备份。删除后会从当前存储中移除，但已有的系统快照或外部备份仍可能保留副本。

2. 敏感信息保护

请勿通过剪贴板传输 VPS 私钥、密码、长期 Token 等敏感凭据。服务器管理员或服务器被入侵时，存储的数据仍可能被读取。

3. 24 小时自动清理与手动删除

保存内容在 24 小时后自动过期，手动删除和自动清理均遵循相同的数据删除规则。首版只保存在 Server 内存中，不写入数据库或自动备份；Server 或 Docker 重启时内容会全部清空。
