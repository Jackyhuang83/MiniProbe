剪贴板

手机和电脑通过同一个 HTTPS 网页互传文字与链接。

⚠ 安全与隐私提醒

1. 数据保存与删除说明

剪贴板内容仅临时保存在服务器内存中，不写入数据库，也不会纳入 MiniProbe 每日自动备份。

  • 手动删除：立即从剪贴板中移除。
  • 自动清理：保存超过 24 小时后自动删除，删除规则与手动删除相同。
  • 服务器重启：所有剪贴板内容自动清空。

注意：删除后，其他设备刷新页面将无法再查看该内容。但如果内容此前已被复制到其他设备，或存在服务器内存快照等独立副本，这些副本不会随之删除。

2. 敏感信息保护

请勿通过剪贴板传输 VPS 私钥、密码、长期 Token 等敏感凭据。服务器管理员或服务器被入侵时，存储的数据仍可能被读取。

3. 24 小时自动清理与手动删除

自动过期和手动删除遵循相同的清理规则。记录只保存在 Server 内存中，Server 或 Docker 容器重启后会全部清空。
