# MiniProbe 订阅中心 DEV3

- 预测：仅对有已知周期和到期日期的**有效手动订阅**计算指定年度/月度的预计扣费。按 USD、JPY 等币种分别显示，不使用实时汇率，也不把预测当作真实已支付。VPS 仅提供月租参考，不确定真实扣费周期，因此不纳入周期预测。
- 日历：按每条手动订阅已知到期日、月付/季付/年付/自定义天数展开；不把未知日期、已暂停或已取消的项目加入。闰月按目标月末处理，避免无效日期。手机小屏适配。
- 备份：SSH 菜单 15 → 10；创建 root-only `subscription-backups/subscriptions-*.json` 文件，文件 0600、目录 0700，不开放公网下载，不输出密码或原始数据到日志。
- 恢复：仅允许从本机备份列表选取；必须明确输入 RESTORE。恢复前自动保存当前账本安全副本，校验版本、记录及历史，原子替换账本；错误文件不覆盖当前数据。备份包含独立网页密码哈希，因此恢复后登录密码可能回退。
- 保持旧版 DEV2 账本格式 version=2，不引入新数据库字段或 Agent 改动。
- **注意**：私有备份仍在 Server 本地磁盘，不是异地灾备。需要时可由 root 经 SSH/SFTP 下载，切勿公开分享备份文件。
- 不修改生产 VPS，不发布正式版本；待 PR CI 通过、合并后再统一 Release 和验收。
