# MiniProbe 剪贴板 · DEV1（Server-only）

## 目标
在手机、Mac、Windows、Android 和 iPhone 的 HTTPS 浏览器之间传输短文本、URL 与代码。不需要 WhatsApp / Telegram，也不需要安装客户端。

- 入口：`/ui/0.4.45-alpha/clipboard.html`（历史版本 HTML 自动跳转）
- 监控 Dashboard 的顶部导航缩短为：监控 / 流量 / 订阅 / 剪贴板；手机端折叠菜单。
- 页面标题、导航只使用“剪贴板”，不使用“私人剪贴板”。
- 最多 50 条；单条 16 KiB；保留换行、Unicode；保存成功即对其他已登录设备可见。
- 12 秒轮询，并在页面重新变为可见时刷新；一键复制、单条删除、清空全部。
- 新增/删除使用已有的订阅中心独立 HTTPS 认证、CSRF 令牌和同源校验；公开 Dashboard 不能读取。
- 可通过订阅中心已有的邮箱验证码认证，剪贴板不增加新的邮箱或密码设置。
- Server-only；没有更改 Agent、监控上报、流量采集或现有订阅数据。

## 始终可见的安全提醒
剪贴板页面顶部固定提供不可关闭的三项说明：

1. **数据保存与删除说明：**剪贴板内容仅临时保存在服务器内存中，不写入数据库，也不会纳入 MiniProbe 每日自动备份。手动删除时立即从剪贴板中移除，保存超过 24 小时后自动清理，Server/Docker 重启时所有内容清空。删除后其他设备刷新页面无法再查看；已经复制到其他设备的内容或服务器内存快照等独立副本不会被一并删除。
2. **敏感信息保护：**请勿通过剪贴板传输 VPS 私钥、密码、长期 Token 等敏感凭据。服务器管理员或服务器被入侵时，存储的数据仍可能被读取。
3. **24 小时自动清理与手动删除：**自动过期和手动删除遵循相同的清理规则，内容不会写入数据库或自动备份。

首版仅使用内存，没有磁盘文件，避免被 MiniProbe 本地每日备份意外收录。删除操作释放记录引用，但无法承诺安全擦除进程内存、交换分区或外部快照。Server 每分钟执行一次清理；即使计时任务尚未执行，GET/POST/DELETE 也会先清理过期记录。

## 验收步骤
1. 仅升级 MiniProbe Server 的测试环境（不要更新 Agent）；以 HTTPS 打开剪贴板页面，确认安全提醒三条均完整显示且无法关闭。
2. 以订阅中心密码登录；手机保存一条多行文本，电脑刷新后复制；电脑保存链接，手机复制。
3. 删除单条、清空全部，再用另一台设备刷新，确认记录消失。
4. 使用无痕窗口测试 Dashboard 公开状态仍不能读取剪贴板 API（401）。
5. 测试没有 CSRF 令牌的 POST/DELETE（403）、非 HTTPS（401）与超过 16 KiB 的文本（400）。
6. 服务器端用测试时钟或单元测试检查 24 小时过期处理；测试 Server/Docker 重启后没有残留记录。
7. 窄屏手机导航应折叠，桌面导航应保持单行；订阅中心和监控仍可访问。
8. 服务器健康检查 `/healthz`、订阅中心读写与 Agent 上报继续正常。

## 发布注意
- `v0.4.45-alpha` 为开发版本，未经测试和合并前不要作为稳定版发布。
- 原有订阅中心密码更改后，旧剪贴板会话随之失效。
- 不允许将剪贴板文本写入访问日志、前端 LocalStorage 或监控事件。
- 内容应视为临时中转，Docker 重启可能早于 24 小时清空。
